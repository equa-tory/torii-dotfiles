# Launcher cheat sheet

Open it with the launcher key (ALT+SPACE here, SUPER on real hardware).

- Down shows the menus, Up on the first row hides them again
- Right (cursor at the end) or Enter opens a menu or runs the item
- Left (cursor at the start) goes back, then closes
- Type to search every menu at once; inside a menu it searches that menu
- `:grin` searches emoji, `v cats` runs a quicklink search, `git` opens its link
- Esc closes, or cancels a question such as a password

Menus: Apps, Trigger (capture, convert, remind, switches), Setup, Install, Remove, Learn, Todo, System.
Menu order is in ~/.config/torii/menu.json.
